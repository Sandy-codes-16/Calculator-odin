# 🧮 JavaScript Calculator

A simple, interactive calculator built using **HTML, CSS, and  JavaScript**.

This project was developed as part of my JavaScript learning journey, with a focus on understanding DOM manipulation, event handling, JavaScript logic, and connecting frontend technologies to build something functional.

## 🚀 Features

- Basic arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- Interactive calculator buttons.
- Real-time display updates.
- CSS hover effects and button-click interactions.
- Basic handling of mathematical edge cases.
- Clear and reset functionality.

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator.
- **CSS3** – Styling, layout, hover effects, and animations.
- **JavaScript ** – Calculation logic, DOM manipulation, and event handling.



## 💻 Getting Started

Want to run this project locally?

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Open `index.html` in your browser.

That's it! No additional dependencies or installations required.
